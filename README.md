# Qubu Resort — Company Profile Website (Hotel, Convention & Recreation)

## 1. Menjalankan project

```bash
npm install
npm run dev

```

Environment:

| File              | Variabel               | Keterangan                                     |
| ----------------- | ---------------------- | ---------------------------------------------- |
| `.env.local`      | `NEXT_PUBLIC_SITE_URL` | dipakai untuk canonical URL, sitemap, OG image |
